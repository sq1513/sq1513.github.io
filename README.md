# 个人学术主页

这是一个适用于 GitHub Pages 的英文静态网页。用浏览器打开 `index.html` 可以在本机预览。

## 修改内容

- 编辑 `index.html` 中的 `Your Name`、院系、简介、研究项目和 `name@example.com`。邮箱链接的地址和显示文字都要更新。
- 将自己的公开版简历保存为 `assets/academic-cv.pdf`，页面中的 CV 按钮会下载这份文件。
- 准备正式发布时，更新页面标题与描述，并删除页脚的示例提示。

## 在 GitHub Pages 发布

1. 登录自己的 GitHub 账号。个人主站的仓库名为 `用户名.github.io`，把“用户名”换成实际的 GitHub 用户名。如已有同名站点，先核对其中的内容。
2. 把本站文件放到仓库的 `main` 分支。打开仓库时应能直接看到 `index.html`，并且 `assets/academic-cv.pdf` 保留原目录结构。
3. 在仓库的 **Settings → Pages** 中，选择 **Deploy from a branch**，再选择 **main** 和 **/(root)**，点击 **Save**。
4. 等 **Settings → Pages** 显示 **Visit site** 后，打开网址检查主页和简历链接。

使用 GitHub 免费账号时，Pages 可以从公开仓库发布。个人主站的默认地址是 `https://用户名.github.io/`。[GitHub Pages 官方指南](https://docs.github.com/en/pages/quickstart)
