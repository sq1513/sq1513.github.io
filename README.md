# Qing Sun 的学术主页

[访问学术主页](https://sq1513.github.io/qingsun.github.io/) · [GitHub 源码仓库](https://github.com/sq1513/qingsun.github.io)

GitHub Pages 从 `main` 分支的根目录发布。站内页面、照片和样式表使用相对链接，以便从 `/qingsun.github.io/` 路径访问。

- `index.html` 包含个人简介、研究兴趣、实验室和联系邮箱。右侧照片为 `assets/qing-sun.webp`。可在 `assets/site.css` 的 `.portrait-slot` 中调整照片大小，在 `.portrait-slot img` 中调整圆角半径。
- `research.html` 按已发表、审稿中和在研三类列出论文题目。已发表论文的题目链接到 DOI。
- `cv.html` 展示教育和研究经历、奖项、论文和技能。当前提供网页简历。
- 三个页面共用 `assets/site.css`。
