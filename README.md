# Qing Sun 的学术主页

GitHub Pages 从 `main` 分支的根目录发布英文网站。

- `index.html` 是首页，包含当前身份、简介和学术资料链接。
- `research.html` 列出期刊论文、作者、期刊、DOI 和研究说明。
- `cv.html` 显示教育经历、研究资助、奖项和论文。更新履历时，同步替换 `assets/academic-cv.pdf`。
- 三个页面共用 `assets/site.css`。首页配图存放在 `assets/solar-and-farmland.webp`。

个人资料来源为 [researchmap](https://researchmap.jp/chinsun)。
