# Qing Sun 的学术主页

GitHub Pages 从 `main` 分支的根目录发布英文网站。

- `index.html` 包含个人简介、研究兴趣、实验室和联系邮箱。右侧照片为 `assets/qing-sun.webp`，最大显示宽度为 180 像素。照片边缘的渐变在 `assets/site.css` 的 `.portrait-slot::after` 中调整。
- `research.html` 按已发表、审稿中和在研三类列出论文题目。已发表论文的题目链接到 DOI。
- `cv.html` 展示教育和研究经历、奖项、论文和技能。当前提供网页简历。
- 三个页面共用 `assets/site.css`。
